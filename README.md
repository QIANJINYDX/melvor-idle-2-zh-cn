# Melvor Idle 2 简体中文补丁 v2.5.0

Windows 一键汉化及恢复工具，已在 0.11.6-alpha.1 / Godot 4.7.2 实机检查。**仍有已知漏译，不宣称百分之百汉化。**

旧版 v1 只设置语言字段，不能解决此游戏版本的中文加载问题，请改用 v2。

## 使用

1. 在 Releases 下载 `Melvor2-Chinese-Patch.exe`，无需 Python。
2. 正常退出游戏，运行工具，选择包含 `Melvor2.exe` 的目录。
3. 点击“一键汉化”，完成后通过 Steam 启动游戏。
4. 撤销时退出游戏，点击“恢复原版”。原版备份会保留。

首次安装需约 650 MB 保存原版备份，另需约 650 MB 临时空间。请保留游戏目录里的 `.before-zh.bak` 和 `melvor-zh-*.json` 文件。游戏更新、文件不匹配或备份损坏时工具会停止；不要用旧备份覆盖 Steam 更新后的游戏。

## 修复内容

游戏只注册英文目录，因此 v2 重建实际加载的目录，复用本地内置中文并补译遗漏。覆盖 11,540 个目录词条，修复 1,869 个名称上下文；翻译游戏数据中 12,258 个显示字段，并补齐等级、任务要求、交互提示、战斗入口和设置中的 124 处场景文本。另修复 120 个程序集显示模板与时间单位，包括护甲说明、精通任务、种植/捕获/地下城计数和战斗属性。

工具修改 `Melvor2.exe` 的资源及两个 DLL 的特定显示字符串/资源。保持资源偏移、ID、引用、数值、格式参数及游戏逻辑不变；不编辑角色存档。原文件通过 SHA-256 校验，支持重复安装、恢复及中断后恢复，防止并发操作。多文件替换并非一个整体原子事务，遇到异常应保留备份并使用恢复功能。

## 实机检查与已知限制

已查看登录、角色选择、离线收益、星象学、仓库、商店、任务、伐木、战斗和设置的可见页面。已重启确认本轮修复。

- 已修复物品通知独立的库存格式模板；本轮尚未再次捕获自然触发的物品通知，动态显示仍待补充验证。
- 实机确认存档中的自定义同伴名称为 `Companion`，保留这个名称。摘要和对话都已确认替换为保存的名称。
- 旧存档自定义仓库标签、玩家名不自动改写；音乐署名、品牌图保留原样。
- 未逐条触发所有任务分支、战斗事件、物品提示和后期内容；词条数量不是完整汉化率。
- 未验证其他游戏版本或模组；EXE 未做代码签名。

详见 [实机检查记录](LOCALIZATION_AUDIT.md)。

## 构建与检查

Windows + Python 3.11 或更新版本：

```powershell
.\build.ps1
python -m unittest discover -s tests -v
python patcher.py --action inspect --game "D:\Steam\steamapps\common\Melvor Idle 2"
```

输出 `dist/Melvor2-Chinese-Patch.exe`。EXE 支持 `--action inspect|apply|restore|self-test --report <JSON路径>`，自动化调用请等待进程退出并读取报告。

仓库只分发工具、补充译文与说明，不包含游戏原始资源、原版备份、用户存档或账号数据。游戏及内置译文归各自权利人所有。
