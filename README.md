# Melvor Idle 2 简体中文补丁 v2.9.1

Windows 一键汉化及恢复工具，已在 0.11.6-alpha.1 / Godot 4.7.2 实机检查。**仍有已知漏译，不宣称百分之百汉化。**

旧版 v1 只设置语言字段，不能解决此游戏版本的中文加载问题，请改用 v2。

## 使用

1. 在 Releases 下载 `Melvor2-Chinese-Patch.exe`，无需 Python。
2. 正常退出游戏，运行工具，选择包含 `Melvor2.exe` 的目录。
3. 点击“一键汉化 + 字体适配”，完成后通过 Steam 启动游戏。
4. 撤销时退出游戏，点击“恢复原版”。原版备份会保留。

首次安装需约 650 MB 保存原版备份，另需约 650 MB 临时空间。请保留游戏目录里的 `.before-zh.bak` 和 `melvor-zh-*.json` 文件。游戏更新、文件不匹配或备份损坏时工具会停止；不要用旧备份覆盖 Steam 更新后的游戏。

## 提示成功但仍是英文

请先在 Steam 的“管理 → 浏览本地文件”确认实际安装目录，再在工具中选择该目录。v2.9.1 修复单文件 EXE 所在目录识别，安装后显示实际修改路径并核对补丁记录。若仍为英文，可在游戏运行时点击“导出诊断”，报告会包含选中 EXE 的校验值、中文目录标记、安装记录是否匹配，以及运行中的 Melvor2.exe 路径；不会读取存档。将报告交给维护者排查。此版本尚未确认所有跨机器失效的根因。

## 修复内容

游戏只注册英文目录，因此 v2 重建实际加载的目录，复用本地内置中文并补译遗漏。覆盖 11,540 个目录词条，修复 1,869 个名称上下文；翻译游戏数据中 12,258 个显示字段，并补齐等级、任务要求、交互提示、战斗入口和设置中的 124 处场景文本。另修复 120 个程序集显示模板，包括护甲说明、精通任务、种植/捕获/地下城计数和战斗属性。

工具修改 `Melvor2.exe` 的资源及两个 DLL 的特定显示字符串/资源。保持资源偏移、ID、引用、数值、格式参数及游戏逻辑不变；不编辑角色存档。原文件通过 SHA-256 校验，支持重复安装、恢复及中断后恢复，防止并发操作。多文件替换并非一个整体原子事务，遇到异常应保留备份并使用恢复功能。

## 中文换行优化

v2.9 将任务摘要及其他说明文本中 91 个场景、192 个控件从按单词换行改为智能换行。长词超出可用宽度时允许按字符断行，适应中文与自定义英文名字混排；不在译文中插入固定换行。原本禁用换行的标题和按钮不统一改成多行。具体范围和后台验证见 [换行检查记录](LAYOUT_AUDIT.md)。

## 中文字体适配

v2.8 为全部 21 个游戏字体资源添加明确的微软雅黑中文后备字体，按原字体设置请求字重和斜体。保留原英文字体、数字字体和页面层级；Windows 会选择本机可用的最接近字重，因此不承诺每档字重都有独立字体文件。需要系统已安装简体中文字体（微软雅黑）。不安装系统字体，不分发微软或游戏字体文件。恢复原版会一并撤销字体适配。

钱和时间单位保持原版，包括 GP、K/M/B/T、/hr、s/h/d 和离线时间格式。

## 实机检查与已知限制

已查看登录、角色选择、离线收益、星象学、仓库、商店、任务、伐木、战斗和设置的可见页面。此前版本已重启检查；v2.8 字体适配和 v2.9 换行优化仅进行后台引擎验证，未重新打开游戏逐页检查。

- 已修复物品通知独立的库存格式模板；本轮尚未再次捕获自然触发的物品通知，动态显示仍待补充验证。
- 实机确认存档中的自定义同伴名称为 `Companion`，保留这个名称。摘要和对话都已确认替换为保存的名称。
- 旧存档自定义仓库标签、玩家名不自动改写；音乐署名、品牌图保留原样。
- 未逐条触发所有任务分支、战斗事件、物品提示和后期内容；词条数量不是完整汉化率。
- 未验证其他游戏版本或模组；EXE 未做代码签名。

详见 [实机检查记录](LOCALIZATION_AUDIT.md)。

## 构建与检查

Windows + Python 3.11 或更新版本：

```powershell
.\build.ps1
python -m unittest discover -s tests -v
python patcher.py --action inspect --game "D:\Steam\steamapps\common\Melvor Idle 2"
```

输出 `dist/Melvor2-Chinese-Patch.exe`。EXE 支持 `--action inspect|apply|restore|self-test --report <JSON路径>`，自动化调用请等待进程退出并读取报告。

仓库只分发工具、补充译文与说明，不包含游戏原始资源、原版备份、用户存档或账号数据。游戏及内置译文归各自权利人所有。

### 可选：后台验证游戏的格式器

在已安装游戏的 Windows 电脑上执行：

```powershell
.\tests\test_smartformat_runtime.ps1 -GamePath 'D:\Steam\steamapps\common\Melvor Idle 2'
```

直接加载游戏自带的 SmartFormat.dll 验证条件分支和列表连接词，不启动游戏、不读写存档、不操作桌面窗口。它验证格式语法和输出，不代替实机界面排版检查。

### 单位与字体偏好

v2.9.1 起保留原版货币单位 GP、数量缩写 K/M/B/T 和时间单位（包括原版时间格式器资源）。中文说明继续保留。数字缩写由游戏共用格式器控制，因此物品数量也沿用原版缩写。

字体只做检查，未替换。见 [字体检查](FONT_AUDIT.md)。游戏正在运行时补丁会拒绝安装；请正常退出后再运行汉化器。
